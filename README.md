# 🐍 Snake Game

🎮 **[Play Snake Game](https://anupammohanag.github.io/Snakegame/)**

A modern and responsive Snake Game built using "HTML, CSS, and JavaScript".

## 🎮 Features

* 🐍 Classic Snake gameplay
* 🎯 Score tracking
* 🏆 High score
* ⏸️ Pause and resume
* 💥 Collision detection
* 📱 Responsive design
* 🎮 Keyboard controls
* 🖱️ Touch controls for mobile devices

## 🕹️ How to Play

* **↑** Move Up
* **↓** Move Down
* **←** Move Left
* **→** Move Right
* Eat the food to grow the snake and increase your score.
* Avoid hitting the walls and yourself.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start playing! 🎮
